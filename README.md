## МАГАЗИН

### Основные фичи магазина
- **Товары (Products):** Просмотр списка доступных продуктов и информации о конкретном товаре.
- **Корзина (Cart):** Возможность добавлять продукты в корзину, просматривать её содержимое и удалять товары из корзины.
- **Заказы (Orders):** Оформление заказа из текущей корзины и просмотр статусов заказов.
